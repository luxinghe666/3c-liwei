# 原拓财务部署方案与费用

2026-10-16；用户已同意按每年不超过 700 元准备后台，具体域名和最终订单仍须付款前核对。尚未购买任何云资源。

## 建议配置

初期 5 人使用、老板与财务主要操作，采用 1 台腾讯云轻量应用服务器：中国内地地域，2 核 CPU / 2 GB 内存 / 40 GB SSD / 3 Mbps / 每月 200 GB 流量。Ubuntu LTS，Docker Compose 运行 Node 24、SQLite 和 Caddy。数据库保持单实例写入；现阶段每次读取完整账本，大规模导入前需压测并改为分页。

手机 App 和电脑浏览器连接同一个 HTTPS 域名。SQLite 和备份放在独立持久卷，重新构建应用不清空账本。数据库不直接对外暴露，初始化老板账号只在服务器终端执行。公网开放 80/443；SSH 限制来源。服务器归用户本人账号所有。

## 上线步骤

1. 700 元年度预算已确认；腾讯云选购入口已打开，当前需要用户完成登录二次验证。登录后选择地域及域名，核对首年、续费、备份及具体订单并获准付款后购买。
2. 确定服务提供者和备案主体；内地网站及面向中国大陆商店发行的 App，按实际适用要求办理相关备案。Apple 个人开发者身份不等于云服务和备案主体已经确定，不把更换服务器地区当作豁免依据。App Store 中国大陆资料要求参考 [Apple App 信息](https://developer.apple.com/cn/help/app-store-connect/reference/app-information/app-information/)。
3. 安装 Docker / Compose，复制代码和 `.env.example` 为 `.env`，填写实际域名与证书联系邮箱。DNS 解析到服务器。
4. 在仓库执行 `docker compose build`，再执行 `docker compose run --rm app node server/init.mjs /app/data/finance.sqlite`。通过终端交互创建唯一老板账号，密码不进入命令历史或 Git。
5. 执行 `docker compose up -d`；检查健康状态、HTTPS、手机网络访问、登录及停用用户。第一次只录入测试数据。不要在公网开启初始化网页。
6. 每天运行 `sh deploy/backup.sh` 创建一致性 SQLite 备份；另外复制至独立加密备份存储。拟保留每日 30 份、月度 12 份，启用前由用户确认保留策略。当前脚本只负责生成服务器内备份，尚未连接异地存储和定时器。
7. 在隔离环境恢复备份并核对金额与审计，再开始正式试用。升级先备份，先在副本验证，避免直接覆盖正式数据库。

## 苹果审核环境

审核只能使用虚构数据，需要单独数据库和审核账号。当前系统为单公司账本，**不具备同一数据库按审核账号隔离账本的能力**。生产账与审核演示账的路由/隔离、真实审核账号及审核说明尚需完成，不能把老板账号或真实经营资料交给审核使用。

隐私政策与支持页面代码已准备，正式域名确定后填写商店链接。隐私政策中的运营主体、托管商、地域及保存期限须依据实际部署补齐，不能把当前草稿当作已发布政策。
