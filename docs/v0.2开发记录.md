# v0.2 开发记录

日期：2026-10-16。阶段：从浏览器演示原型升级为服务端联机测试版。

## 本次完成

保留八个业务入口，所有写入改由 Node 服务处理。SQLite 保存账号、会话、当前账本、去重记录和操作审计。每次记账在同一事务中写入账本与审计，失败全部回滚。

客户端只提交单项业务和已知版本。同一提交重试只记一次，旧版本写入提示刷新。金额按整数分校验，比例毛利用整数乘除处理，避免大额浮点乘法丢失尾差。

新增初始化、老板／财务登录、成员开通与停用、密码修改／重置、基础资料建档和账户命名。删除原型角色切换和重置入口，关账由服务端校验。老板可导出业务副本，管理员有整库备份恢复命令。

## 验证

- 43 项自动测试通过，包括原有 22 项业务验证。
- 验证未登录拒绝、CSRF／跨站拒绝、角色权限、重复请求、并发冲突、失败回滚和数据格式校验。
- 从零完成预付→锁货→发货→入库→销售→分次收款→跨月退货，金额、库存及利润符合预期。
- 重启保留数据；在线备份恢复至新文件，完整性检查成功，旧会话清空。
- 实际浏览器完成初始化、回款 1000 元并刷新核对、客户建档、创建财务账号、关账／反关账、退出和财务角色验证。
- 1280px 电脑与 390px 手机宽度无整页横向溢出，控制台无错误。使用独立测试数据库，用户初始化入口保留空白。

## 下一步

先接入用户提供的博远购销及串号文件，开发可查重、可回滚的真实导入，再补期初建账、金额核对和普通业务更正。之后补配件平均成本、往来退款和运费付款闭环，用真实样例完成验收。

iPhone 继续按「公司内部登录使用、电脑用浏览器」规划。本版提供后端基础，尚无 Xcode 工程或可上传安装包。开发者会员、服务器／域名、隐私政策和审核材料仍待完成，尚未提交 App Store。

完整需求以需求确认稿为准；已实现范围与限制见《服务端使用说明》。本版仍不能直接替代博远或财务正式账。
