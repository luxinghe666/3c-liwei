# 网页更新存档 · 2026-10-19

本次保存当前网页与所需共享后台，保留原有 iOS 工程及部署配置。网页现有账户管理、期初建档、对账与流水更正、客户账期、利润分析、型号数量库存及通知模块是 Galaxy 交互的运行依赖，随网页一并同步。

## 网页交互

- 采用 Galaxy / Uiverse 的实际按压按钮、期初确认勾选和圆环加载组件；固定源提交和 MIT 许可见 `third-party/galaxy/`。
- 支持跟随系统、浅色、深色；偏好只保存于当前浏览器。
- 保存及登录按钮随真实请求显示等待状态，完成提示以接口结果为准。
- 客户卡片提供选择联动及键盘操作；手机布局使用单列金额卡片、长名称换行和完整宽度的期初弹窗。

## 验证

73 项既有无监听回归和 17 个 JavaScript 语法检查通过。真实浏览器已核验浅/深色、税费弹窗打开与取消、期初勾选及空格键切换、客户筛选联动、320/390 像素手机布局和 1280 像素桌面布局；控制台未发现警告或错误。

浏览器检查没有提交业务表单，账本版本保持 10。实际重新登录与财务保存成功/失败仍待实际业务验收。此次存档不等于云端部署、iOS 发布或 App Store 上架。

## 恢复与运行

使用 Node.js 24.13 或更新的 24 LTS。运行 `npm start` 后访问 `http://127.0.0.1:4318/`。源代码不包含数据库、密码、APNs 私钥或真实业务表格；在新环境恢复时需要单独配置账本和账号。

本机完整源码压缩包另存于工作区 `outputs/`，附 SHA-256 校验；其中包含本地 iOS 等尚未同步的工作文件。本次 GitHub 上传目录为 `dist/`、`server/`、相关根目录测试与配置、`third-party/galaxy/`、本地后台启动脚本和本文。
