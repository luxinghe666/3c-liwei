# 3C 财务工作台

面向 3C 供应链业务的财务软件交互原型，包含账户流水、采购、销售、库存串号、费用票据和回款利润。当前使用模拟数据，尚不具备正式账本的持久化、多人权限及备份能力。

## 本地体验

直接用浏览器打开 `preview/财务工作台交互原型.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:8765/`。演示操作保存在当前浏览器，不同设备不共享数据。

## 验证

Node.js 20 或更新版本，无第三方依赖：

```sh
npm test
npm run check
```

22 项业务模型测试通过，覆盖 FIFO 回款、比例利润、老板往来、采购运费、退货、税费和历史日期限制。真实浏览器点击流程及桌面／手机视觉验收尚待完成。

## 文件结构

- `dist/`：静态应用源码。
- `model.test.mjs`、`regression.test.mjs`：业务测试。
- `preview/`：可单独打开的 HTML 原型。
- `docs/`：需求、导入核对、首版流程、使用说明和续做记录。

历史补录如需重算后续收款或余额抵扣，原型会明确拒绝。真实 Excel 导入、期初建账、正式身份权限、服务端存储和完整月结等仍需开发。

需求文档含实际经营资料，完整项目适合保存于私有仓库。仓库不包含原始经营表格、截图或凭证。
