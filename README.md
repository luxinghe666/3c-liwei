## 本地体验

使用 Node.js 24.13 或更新的 24 LTS 版本，无第三方运行依赖。在仓库根目录运行：

```sh
npm start
```

也可在访达双击 [启动本地测试后台.command](scripts/启动本地测试后台.command)，保留打开的终端窗口。启动器使用现有数据库，不会重置账本；自动执行环境此前无法监听端口，因此目前需手动启动。

访问 <http://127.0.0.1:4318/>，首次创建老板账号，密码至少 12 位，再在模拟器使用同一账号登录。没有预设账号或默认密码。可选择空白测试账（自行新增收付款账户）或含虚构资料的演示测试账。老板在「基础资料与设置 → 成员管理」开通财务账号。

本地数据保存在 `data/finance.sqlite`，关闭页面或重启服务不会清空。不同浏览器连接同一个服务即可共享账本。默认只监听本机；云端已安装独立的空白账本服务，手机外出查看仍需完成备案、管理员初始化和 HTTPS。

`preview/财务工作台交互原型.html` 保留 v0.1 离线原型，与新数据库互不关联。`dist/` 现在必须通过 Node 服务使用。

## 文件结构

- `dist/`：浏览器界面及共享业务规则。
- `server/`：Node / SQLite 后端、备份恢复命令。
- `model.test.mjs`、`regression.test.mjs`、`server.test.mjs`：业务与接口测试。
- `preview/`：可单独打开的 HTML 原型。
- `docs/`：需求、导入核对、首版流程、使用说明和续做记录。

使用方式、备份恢复、移动平均成本规则及苹果推送接入步骤见 [服务端使用说明](docs/服务端使用说明.md)。新版普通资金流水可预览后更正或撤销；不支持对采购、销售或期初任意回溯改写。移动加权库存业务需按日期顺序录入。
