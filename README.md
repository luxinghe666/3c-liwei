# 3C 财务工作台

v0.2.0 联机测试版。在原有 8 个业务页面上增加共享数据库、老板／财务登录、服务端记账、关账、审计及备份恢复。适合先用测试业务验证流程；真实 Excel 导入、期初建账、历史更正和 iPhone App 尚未完成。

## 本地体验

使用 Node.js 24.13 或更新的 24 LTS 版本，无第三方运行依赖。在仓库根目录运行：

```sh
npm start
```

访问 <http://127.0.0.1:4318/>，首次创建老板账号，密码至少 12 位。没有预设账号或默认密码。可选择空白测试账（6 个账户零余额）或含虚构资料的演示测试账。老板在「导入与设置 → 成员管理」开通财务账号。

数据保存在 `data/finance.sqlite`，关闭页面或重启服务不会清空。不同浏览器连接同一个服务即可共享账本。默认只监听本机，尚未部署到互联网；手机外出查看需要后续部署服务器和 HTTPS。

`preview/财务工作台交互原型.html` 保留 v0.1 离线原型，与新数据库互不关联。`dist/` 现在必须通过 Node 服务使用。

## 验证

在项目根目录运行：

```sh
npm test
npm run check
```

43 项自动测试通过，覆盖原有业务规则以及登录权限、CSRF、并发写入、重复提交、失败回滚、重启持久化、关账、停用账号和整库备份恢复。已在实际浏览器验证初始化、登录、回款保存与刷新、建档、成员创建、关账／反关账与退出，检查了 1280px 电脑及 390px 手机布局。

## 文件结构

- `dist/`：浏览器界面及共享业务规则。
- `server/`：Node / SQLite 后端、备份恢复命令。
- `model.test.mjs`、`regression.test.mjs`、`server.test.mjs`：业务与接口测试。
- `preview/`：可单独打开的 HTML 原型。
- `docs/`：需求、导入核对、首版流程、使用说明和续做记录。

使用方式、备份恢复和业务限制见 [服务端使用说明](docs/服务端使用说明.md)，阶段进度见 [v0.2 开发记录](docs/v0.2开发记录.md)。历史补录如需重算后续收款或余额抵扣，仍会明确拒绝；完整普通业务更正、配件平均成本及月结闭环还需继续开发。
